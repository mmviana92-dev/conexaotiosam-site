English

Who we are

This website belongs to the Conexão Tio Sam YouTube channel (youtube.com/@conexaotiosam_), owned and operated by Michel Viana. Contact: conexaotiosan@gmail.com.

This website

This website does not use cookies, analytics, advertising or any tracking. It has no accounts and no forms, and it does not collect personal data. Video thumbnails are loaded from YouTube's image servers (i.ytimg.com), and links to videos open on YouTube, which is governed by Google's own privacy policy. The site is hosted on GitHub Pages, which may keep standard technical logs (such as IP addresses) for security.

The agentTube app

agentTube is a private application used only by the channel owner, Michel Viana, to upload and manage videos on his own YouTube channel through the YouTube Data API. It is not offered to the public and has no other users.

  • Data accessed: only the owner's own YouTube channel, through the scopes he authorizes (for example, uploading videos, setting titles, descriptions, thumbnails, captions and publishing dates, and reading his channel's video status, comments and analytics).
  • Use: the data is used only to provide these functions to the owner on his own channel.
  • No third-party data: agentTube does not collect, sell, rent or share data of any third party. It does not transfer Google user data to anyone, does not use it for advertising, and does not use it to train AI models.
  • Storage: the OAuth tokens are stored only on the owner's own computer and are never published or sent to other parties.
  • Limited Use: agentTube's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • How to revoke access: the account owner can remove agentTube's access at any time at myaccount.google.com/permissions. Removing access stops the app from using the channel; tokens stored locally become invalid.
  • Data deletion: to request deletion of any data related to agentTube, write to conexaotiosan@gmail.com.

Português

Quem somos

Este site pertence ao canal Conexão Tio Sam no YouTube (youtube.com/@conexaotiosam_), de propriedade de Michel Viana, que também o administra. Contato: conexaotiosan@gmail.com.

Este site

Este site não usa cookies, ferramentas de análise, anúncios nem qualquer rastreamento. Não tem contas nem formulários e não coleta dados pessoais. As miniaturas dos vídeos são carregadas dos servidores de imagem do YouTube (i.ytimg.com), e os links dos vídeos abrem no YouTube, que segue a política de privacidade do Google. O site é hospedado no GitHub Pages, que pode guardar registros técnicos comuns (como endereço IP) por segurança.

O app agentTube

O agentTube é um aplicativo privado, usado só pelo dono do canal, Michel Viana, para enviar e gerenciar vídeos no próprio canal do YouTube por meio da YouTube Data API. Ele não é oferecido ao público e não tem outros usuários.

  • Dados acessados: só o próprio canal do dono, dentro das permissões que ele autoriza (por exemplo: enviar vídeos; definir títulos, descrições, thumbnails, legendas e datas de publicação; e ler o status dos vídeos, os comentários e as estatísticas do canal).
  • Uso: os dados servem só para essas funções, no próprio canal do dono.
  • Sem dados de terceiros: o agentTube não coleta, não vende, não aluga e não compartilha dados de terceiros. Não transfere dados de usuários do Google a ninguém, não os usa para publicidade e não os usa para treinar modelos de IA.
  • Armazenamento: os tokens de acesso (OAuth) ficam só no computador do dono e nunca são publicados nem enviados a outras pessoas.
  • Uso limitado: o uso e a transferência de informações recebidas das APIs do Google pelo agentTube seguem a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).
  • Como revogar o acesso: o dono da conta pode remover o acesso do agentTube a qualquer momento em myaccount.google.com/permissions. Com o acesso removido, o app deixa de usar o canal e os tokens guardados no computador perdem a validade.
  • Exclusão de dados: para pedir a exclusão de qualquer dado ligado ao agentTube, escreva para conexaotiosan@gmail.com.
